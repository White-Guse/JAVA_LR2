# Графический редактор

Учебное приложение на Java Swing. Можно рисовать карандашом, добавлять фигуры,
выделять и перемещать их, собирать группы и сохранять рисунок.
Используются MVC, наследование фигур и паттерн «Компоновщик».

[Задание](https://github.com/olgmina/SWEngineering-technics.github.io/blob/gh-pages/Labs/prTask_GraphEditor.md)

## Запуск

Нужен JDK 17 или новее. Откройте `pom.xml` в IntelliJ IDEA и запустите
`com.example.app.Application`. Для запуска без IDE используйте `run.bat`.
После изменения исходников сначала выполните `build.bat`.

```text
mvn test
mvn package
java -jar target/shape-prototype-1.0-SNAPSHOT.jar
```

## Управление

Выберите инструмент в списке сверху. Фигура добавляется щелчком на холсте,
карандаш и маркер рисуют с зажатой левой кнопкой. Кнопка «Цвет» задаёт цвет
для следующих объектов. Новые фигуры рисуются контуром; заливку можно включить
в свойствах.

В режиме «Выделение» фигуры можно перетаскивать. Shift + щелчок выбирает
несколько объектов, а перетаскивание пустого места выделяет рамкой.
Операции группировки, удаления и изменения порядка находятся в меню «Правка».

На вкладке «Объекты» можно выбрать отдельный элемент внутри группы, а также
скрытую или закреплённую фигуру. На вкладке «Свойства» задаются координаты,
размеры, текст, цвет и эффекты. Изменения действуют после нажатия «Применить».
Ширина и высота должны быть положительными, толщина линии — от 1 до 30.
У круга и квадрата стороны остаются равными. Для объёма нужна включённая заливка.

«Рисунок» выбирает PNG/JPEG для заливки. Изображение сохраняется внутри файла
рисунка. «Без рисунка» убирает текстуру после применения. «Стиль всем» переносит
оформление образца на остальные объекты, сохраняя их расположение и размеры.

Меню «Файл» содержит создание, открытие и сохранение документов `.sheet`.
Сочетания: Ctrl+N, Ctrl+O, Ctrl+S. Перед закрытием изменённого рисунка программа
предлагает его сохранить. Старые файлы `.sheet` продолжают открываться.

## Структура

| Пакет | Что находится |
|---|---|
| `shapes` | Фигуры, линия карандаша, группа и оформление |
| `model` | Объекты, выделение, редактирование и сохранение |
| `view` | Окно, холст и свойства |
| `controller` | Обработка кнопок и мыши |
| `app` | Запуск приложения |

Группа `ShapeGroup` наследует `Shape` и хранит список других `Shape`.
Обычные фигуры — листья, группа — составной объект. При перемещении или изменении
размеров группы операция применяется к её элементам, включая вложенные группы.
Окно не меняет модель самостоятельно: действия проходят через контроллер.

## Требования задания

| Пункт | Где проверить |
|---|---|
| FUN-01 | Список инструментов, мышь и «Правка → Удалить» |
| FUN-02 | «Правка → Вперёд / Назад» |
| FUN-03 | Размеры группы и свойства её отдельных элементов |
| FUN-04 | «В группу / Разобрать» и дерево объектов |
| FUN-05 | Флажки «Тень» и «Объём» |
| FUN-06 | «Рисунок» для фигуры или группы |
| FUN-07 | «Правка → Стиль всем» |
| FUN-08 | Поле «Текст»: шрифт зависит от размеров фигуры |
| FUN-09 | Флажки «Виден» и «Выделяется» |
| FUN-10 | «Файл → Сохранить / Открыть» |
