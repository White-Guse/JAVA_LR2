# Этапы разработки

Инкремент — шаг, после которого приложение получает дополнительные возможности
и остаётся рабочим. Ниже приведена карта уже выполненных этапов по настоящей
Git-истории. Метки версий добавлены при оформлении этой карты; старые коммиты
и даты не изменялись. Это не подтверждение конкретной формулировки преподавателя.

| Этап | Результат | Версия |
|---|---|---|
| 1. MVC и фигуры | Выбор и отображение одной фигуры, наследование, отдельные модель, окно и контроллер | `increment-1-mvc` |
| 2. Редактирование | Несколько объектов, карандаш, перемещение, группы, свойства, эффекты и сохранение | `increment-2-editor` |
| 3. Проверка | Тесты модели и интерфейса, ручные сценарии, проверка требований задания | `increment-3-tests` |
| 4. Упрощение | Обычные меню, список инструментов, белый холст и текстовые поля вместо декоративного оформления | `increment-simple-ui` |

Четвёртый этап является переработкой интерфейса по обратной связи, а не добавлением
нового функционального требования. Возможности второго этапа сохранены.
Модель, интерфейс и проверки развивались в отдельных ветках, которые затем
объединялись в `develop`. Упрощение выполнено в `codex/simpler-editor`.

Для просмотра исходников этапа без переключения своей рабочей ветки:

```text
git show increment-1-mvc:src/main/java/com/example/model/EditorModel.java
git log --graph --oneline --all
```

Для отдельного каталога выбранной версии:

```text
git worktree add ../LR2-increment-1 increment-1-mvc
```

В созданном каталоге можно выполнить `build.bat` и `run.bat`.
Не переключайте версии в основной папке при наличии несохранённых изменений.
